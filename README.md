## 📚 Understanding the Tech (In Plain Words)

Under the hood, prime-agent uses something called **Reinforcement Learning**, or RL for short. That's the "RL" in "RLM agent." In simple terms:

- **Regular programs** follow pre-written rules
- **Prime-agent** tries different approaches, sees what works, and remembers it for next time

The "agent" part means it works autonomously - it doesn't need you to babysit it constantly.

Prime-agent's "long-running autonomous tasks" ability means it can handle jobs that take many steps over long periods. You could set it up to check something every hour all week, and it will faithfully do exactly that.
